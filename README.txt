PUBALI TRAVELS & TOURS — GitHub Pages package

1. Upload index.html and admin.html to the ROOT of your GitHub repository.
2. Settings > Pages > Deploy from branch > main > /(root) > Save.
3. Public site: index.html
4. Admin demo: admin.html

IMPORTANT:
GitHub Pages cannot run PHP/MySQL and cannot provide a secure shared database by itself.
The supplied admin.html is only a local-browser demo, not a production registration database.
For the requested real admin dashboard where registrations from all visitors are stored centrally,
you need a backend/database such as Supabase, Firebase, or PHP/MySQL hosting.
